# Security Policy

## Supported Versions

We actively provide security patches and dependency updates for the following versions of TAMEV:

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| < 0.0.1 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within TAMEV, please do **NOT** open a public issue.

Instead, please report security concerns directly to the maintainers:
- **Email**: `security@tamkimd.dev` (or open a private security advisory via GitHub Security Advisories tab).
- Include detailed steps to reproduce the issue, along with proof of concept if available.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure and patch timeline.
